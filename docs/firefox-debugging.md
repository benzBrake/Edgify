# Firefox 调试约定

具体调试操作使用 `debugging-firefox` skill；本文补充项目的环境参数、连接和收尾约定。

## 环境参数

- Firefox 可执行文件、RDP 端口、配置文件目录等本机参数由用户在任务中指定，或写入项目根目录的 `AGENTS.local.md`。
- 不硬编码 Firefox 安装路径、调试端口、用户配置目录、代理地址或进程 ID。
- 未指定端口时，先检查 `AGENTS.local.md`；仍无法确定时，向用户确认或选择当前空闲的高位端口，并在执行前明确告知。

## 连接

- 优先连接用户已启动且已授权调试的 Firefox 实例。
- RDP 仅连接和监听回环地址 `127.0.0.1`；启动监听前检查目标端口占用情况。
- 启动调试服务使用 `--start-debugger-server <PORT>`，传给实际的 Firefox 浏览器可执行文件，而非便携版或第三方启动器。
- 首次连接若触发远程调试授权提示，由用户在浏览器中确认，不得绕过或自动接受。

## 收尾

- 关闭本次创建的调试客户端，并报告仍在运行的 Firefox 进程或监听端口。
- 关闭客户端不代表调试监听已经关闭。
